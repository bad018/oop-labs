# Множественное и виртуальное наследование 🍿

## 📋 Задание

В данной лабораторной работе требуется изучить механизмы **множественного** и **виртуального** наследования в языке C++ на практике. Для этого необходимо решить задачу построения иерархии классов, при которой создание одного объекта приводит к выводу на экран слова POPCORN.

## Основные требования

### Иерархия классов
- Каждый класс называется одной **заглавной буквой** латинского алфавита (например, `A`, `B`, `C` …).
- Класс содержит **только конструктор по умолчанию**, который выводит на экран соответствующую букву.
- Тело класса **не изменяется** – разрешается менять **только строку объявления** (указывать базовые классы и добавлять `virtual` при необходимости).

**Пример класса:**
```cpp
class X {
public:
    X() {
        std::cout << "X";
    }
};
```

## 🏗️ Структура программы

Функция `main` должна содержать **только** создание одного объекта некоторого класса `X` и ничего более:

```cpp
int main() {
    X obj;
}
```

Задача состоит в том, чтобы организовать структуру наследования между классами
таким образом, чтобы при запуске программы на экран выводилось слово POPCORN.
Помимо программной реализации требуется представить схему построенной иерархии
классов, наглядно отражающую связи наследования между ними. Схема может быть выполнена в произвольной форме (от руки, в графическом редакторе и т.п.).
