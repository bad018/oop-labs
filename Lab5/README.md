# 🎯 Alchemy
## 📋 Задание Игра «Алхимия»

В этом варианте предлагается реализовать упрощенную версию игры «Алхимия». Суть игры заключается в комбинировании базовых элементов для получения новых веществ.

## Основные требования

**Иерархия классов:**
- Абстрактный базовый класс `Element` с protected полем для имени элемента
- Четыре основных природных элемента:
  - `Fire` (Огонь)
  - `Water` (Вода) 
  - `Earth` (Земля)
  - `Air` (Воздух)

**Механика взаимодействия:**
- Перегрузка оператора `operator+` для взаимодействия элементов
- Оператор принимает два указателя на `Element` и возвращает указатель на новый объект или `nullptr`
- Использование `typeid` для идентификации типов во время выполнения
- Порядок сложения не должен иметь значения

**Таблица рецептов:**
- Fire + Water → Steam (Пар)
- Earth + Water → Mud (Грязь)  
- Fire + Earth → Lava (Лава)
- Air + Fire → Energy (Энергия)

**Игровой процесс:**
- Начальный набор: только базовые элементы
- Пользователь выбирает индексы двух элементов
- При успешной комбинации новый элемент добавляется в конец списка
- Исходные элементы не расходуются

## Дополнительное задание

**Измененная логика:**
- Элементы тратятся при взаимодействии
- Реализация разделения сложных элементов через перегрузку `operator-`
- При вычитании сложного элемента он удаляется, а составляющие добавляются в конец списка
- Базовые элементы не могут быть разделены
